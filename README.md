# Take 5 – Waddi site

The contractor Take 5 page for the Waddi site, at **https://genus-ymt-she.github.io/waddi-take5/**.

Contractors scan the Take 5 poster with their phone camera, type the poster code once, then their name and company, and complete
the Take 5. It is sent to the Waddi SHE team.

## How it works
- `index.html` frames the Take 5 page of the Waddi site inspection app (`/rubee/#c5`, the same `genus-ymt-she.github.io` site).
  The form, the poster code check, the email with its PDF, the KPIs and the daily summary all come from there – nothing is copied
  here, so a fix to the Take 5 there applies here straight away.
- Nothing is stored in this repository or passed in the web address: no keys, codes, names or records.
- The poster (with the QR for this address and the code) is made in the app: Settings › Contractor Take 5 (Manager mode).

## Publishing
GitHub Pages: Settings › Pages › Build and deployment › Deploy from a branch › `main` / `(root)`.
